# Presentation and Referencing：评分项对应表

`Presentation and Referencing` 是第六个评分维度，但不是独立的正文内容章节。它通过整篇正式论文共同体现。

| 评分项 | 正式论文章节 |
|---|---|
| Introduction/Literature Review | 第一章：*Introduction and Literature Review*（引言与文献综述） |
| Case/Hypothesis/Aims/Objectives | 第二章：*Research Question and Objectives*（研究问题与目标） |
| Design of Study or Method | 第三章：*Methods*（研究方法） |
| Results | 第四章：*Results*（结果） |
| Discussion | 第五章：*Discussion and Conclusion*（讨论与结论） |
| Presentation and Referencing | 贯穿全文，并由不编号的 References 部分完成。 |

| 评分要求 | 论文中的实际对应位置 |
|---|---|
| 总体结构清楚 | 五个编号章节按照前五个评分项的顺序一一排列。 |
| 排版一致 | UCL 模板统一控制页面、字体、行距、标题层级和连续页码。 |
| 图片与表格 | 前置部分包含 List of Figures 和 List of Tables；正式图表均在正文中先被引用，自动编号并附有 caption。 |
| 来源说明 | 数据集样本图和第三方材料在 caption 或相邻正文中注明来源。 |
| 文内引用 | 对既有研究、数据集、模型和方法的陈述使用 LaTeX citation，并连接到经过核实的 bibliography record。 |
| 完整参考文献表 | Chapter 5 后设置不编号的 `References`，由 `References.bib` 按统一格式自动生成。 |

这个对应表只用于后台检查，不应作为带有自我说明性质的 Chapter 6 复制进正式论文。
