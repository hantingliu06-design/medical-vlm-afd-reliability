# 第一章：文献综述

## 医疗视觉问答

VQA 要求模型根据自然语言问题回答图像内容，因此问题会改变需要关注的视觉证据（Agrawal 等，2017）。医学数据集把这种界面引入临床图像：VQA-RAD 提供临床人员撰写的放射影像问题，PathVQA 把病理图像与器官及征象问题连接起来，SLAKE 又加入语义标签和外部医学知识（Lau 等，2018；He 等，2020；Liu 等，2021）。Surgical-VQA 随后研究手术场景中的器械、解剖、动作和位置（Seenivasan 等，2022）。这些基准使定向医学图像提问成为可能，但通常把临床问题简化为一张图、一个短问题和有限参考答案，因此看似合理的答案并不能证明完整临床推理或可靠的病例级行为。

## 通用视觉语言模型

早期医学 VQA 系统通常针对单一数据集和答案空间训练，现代 VLM 则连接大型视觉编码器和语言模型。Transformer 提供通用注意力序列结构，CLIP 对齐图像和文本表征，BLIP-2 通过可学习接口连接冻结的视觉与语言组件（Vaswani 等，2017；Radford 等，2021；Li 等，2023）。视觉指令微调进一步使 LLaVA 和 Qwen-VL 无需任务专用分类头即可回答新图像指令（Liu 等，2023；Bai 等，2023），LLaVA-Med 和 MedGemma 则加入生物医学数据与指令（Li 等，2023；Sellergren 等，2025）。更广泛的能力很有价值，但不透明的训练混合和自由生成使视觉接地与领域验证更加重要（Moor 等，2023；Wiens 等，2019）。

## 零样本评价

零样本评价在不使用目标任务标注样本训练的情况下测试模型，指令微调 VLM 可以在推理时根据新的图像和文本 prompt 完成任务（Liu 等，2023；Bai 等，2023）。但是，零样本并不代表模型从未在预训练中见过相关图像、描述或问题。结果还受 prompt 表述、聊天模板、解码设置和输出长度影响，同一内容可能被返回为单词、句子或解释。因此，零样本结果描述的是某个具体检查点在明确协议下的行为，不能把差异直接归因于结构、参数规模或训练数据，也不能证明临床迁移能力（Li 等，2023；Sellergren 等，2025）。

## 基于参考答案的评价

自由形式 VQA 通常使用 BLEU、ROUGE-L 和 METEOR 与参考答案比较：BLEU 计算截断 n-gram 精确率，ROUGE-L 使用最长公共子序列，METEOR 进行词对齐并加入片段惩罚（Papineni 等，2002；Lin，2004；Banerjee 和 Lavie，2005）。这些指标奖励不同性质，模型排名可能随指标改变，短医学答案中的同义词和不同具体程度会进一步放大这一问题（Lau 等，2018；He 等，2020）。汇总分数还会隐藏特定条件下的系统性失败，也无法说明模型是否使用图像或识别自身不确定性（Ribeiro 等，2020）。因此，参考指标是有用的答案质量工具，但不是完整可靠性指标。

## 幻觉与失败检测

VLM 幻觉包括图像没有支持的对象、属性或关系（Liu 等，2024），无参考检测和扰动方法尝试在推理时不使用正确答案的情况下发现这些问题（Li 等，2024；Zhang 等，2024）。不确定性量化描述模型或输出表现得多不确定，自动失败检测则检验某个分数能否把预先定义的错误排在非错误之前，两者并不相同。失败检测必须有明确终点，因为变化明显的分数未必能够区分答案好坏；语言模型置信度也常常校准不足，更高准确性不能保证置信度更可靠（Guo 等，2017；Jiang 等，2021）。流畅度、置信度、答案质量和失败检测是有关联但不同的性质。

## 采样与语义不确定性

黑盒不确定性可以通过对同一输入采样多个答案来估计。精确频率简单透明，但会把改写视为分歧，也可能把重复错误判断为低不确定性。语义熵和成对语义方法比较答案含义，更适合自由形式输出（Farquhar 等，2024；Nguyen 等，2025），但仍受表征模型、分组规则、采样数量和解码协议影响。更重要的是，答案之间的一致并不保证它们回答了问题。手术 VQA 研究因此把问题对齐加入不确定性计算，并强调答案一致性与问题有效性必须分开（Carlini 等，2026）。任何采样方法都需要根据明确的失败标签进行评价，不能预设其普遍可靠。

## 选择性预测与数据分布变化

选择性预测通过接受低风险病例并拒绝或转交其余病例，使失败分数具有实际用途，并形成覆盖率与错误之间的权衡（Geifman 和 El-Yaniv，2017）。有效检测器应在移除高风险病例后提高保留答案质量，但这种行为可能在测试分布变化时减弱。选择性问答和不确定性研究表明，置信度与正确性的关系会跨领域改变（Kamath 等，2020；Ovadia 等，2019），放射影像外部验证研究也经常发现离开开发数据后性能下降（Yu 等，2022）。因此，模型排序和选择性表现必须在目标图像模态、问题类型、临床背景和失败比例下重新评价。

## 尚未解决的研究空白

现有研究分别推进了医学答案生成和可靠性评价，但通常只问哪个模型的答案最好，或在单一模型与任务中比较不确定性方法。参考指标不能证明视觉接地或病例级失败意识，采样与语义分数也可能稳定但错误，并随数据分布改变（Farquhar 等，2024；Carlini 等，2026；Ovadia 等，2019）。关于不同医疗 VLM 在答案质量和失败检测被分开评价时是否保持相同排名，以及这种关系是否跨数据集稳定，目前证据较少。因此需要双轴评价：greedy response 衡量答案效用，检测器排序与选择性行为衡量失败意识，任何一个维度都不能由另一个推断。
