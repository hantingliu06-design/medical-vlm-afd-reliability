# Presentation and Referencing: rubric mapping

`Presentation and Referencing` is the sixth marking criterion, but it is not a separate content chapter. It is evidenced throughout the submitted dissertation.

| Marking criterion | Dissertation chapter |
|---|---|
| Introduction/Literature Review | Chapter 1: *Introduction and Literature Review* |
| Case/Hypothesis/Aims/Objectives | Chapter 2: *Research Question and Objectives* |
| Design of Study or Method | Chapter 3: *Methods* |
| Results | Chapter 4: *Results* |
| Discussion | Chapter 5: *Discussion and Conclusion* |
| Presentation and Referencing | Applied throughout the dissertation and completed by the unnumbered References section. |

| Marking requirement | Location in the dissertation |
|---|---|
| Clear overall structure | The five numbered chapters follow the first five marking criteria in the same order. |
| Consistent presentation | The UCL template controls page layout, typography, spacing, headings, and continuous page numbering. |
| Figures and tables | The front matter contains a List of Figures and a List of Tables. Every formal figure and table is introduced in the text, numbered automatically, and supplied with a caption. |
| Source acknowledgement | Dataset images and third-party material are attributed in their captions or surrounding text. |
| In-text referencing | Claims about prior work, datasets, models, and methods use LaTeX citation commands linked to verified bibliography records. |
| Complete reference list | The unnumbered `References` section follows Chapter 5 and is generated from `References.bib` using one consistent bibliography style. |

This mapping should remain a workbench check. It should not be copied into the dissertation as a self-referential Chapter 6.
